# Investigation Report

## Scenario

This lab investigated AWS management events generated through the AWS Console.
The objective was to validate CloudTrail visibility and least-privilege access
control enforcement.

## IAM Enumeration Investigation

CloudTrail Event History in `us-east-1` recorded IAM actions including
`ListUsers`, `ListGroups`, `ListRoles`, `ListAccessKeys`, `ListMFADevices`,
and `GetAccountSummary`.

These actions were generated by an authorized administrative identity during
testing. In a production environment, this pattern should be investigated when
it is unexpected for the identity, source IP address, time of day, or role.

## Denied API Investigation

CloudTrail recorded a denied EC2 `DescribeRegions` request in `us-east-2`.

The event contained:

- `errorCode`: `Client.UnauthorizedOperation`
- `eventType`: `AwsApiCall`
- `managementEvent`: `true`
- `readOnly`: `true`
- `sessionCredentialFromConsole`: `true`

The event showed that a least-privilege policy prevented an API action that was
not explicitly allowed by an identity-based policy.

## Conclusion

CloudTrail provided the necessary audit data to identify the principal, API
action, source service, Region, and authorization outcome. The lab validated
both visibility into IAM management activity and detection of a denied API call.
